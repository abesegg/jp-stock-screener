# 勝ち銘柄の研究の記録

`analysis/winner_study.py`の実行結果と考察の記録。データが増えたら再実行し、日付の見出しを付けて追記する。

## 目的と方法

- **目的**: `signal_study.py`（シグナルが出た銘柄がその後どうなったか）とは逆向きに、「実際に大きく上がった銘柄（勝ち銘柄）を、スクリーニングは拾えていたか」を調べ、見逃し・死角を見つける。オニールの「モデルブック」（過去の大化け株の上昇前の姿の研究）と同じ考え方
- **実行**: プロジェクトフォルダで`uv run python analysis/winner_study.py`。`--export`でエピソード1件ごとの一覧を`analysis/winner_episodes.csv`（git管理外、BOM付きUTF-8）に書き出す。データは読むだけで書き換えない
- **データ**: `ohlcv_history.csv`と`daily_ohlcv.csv`をつなげた約2年分。対象は流動性フィルタ通過銘柄
- **勝ち銘柄の定義**: 各月の最初の営業日を起点に、60営業日後のTOPIX（1306.T）に対する超過リターンが**+30%以上**。+50%以上は「大化け」として別にも集計。2024年10〜12月はEMAの助走期間のため、起点は2025年1月以降
  - 相対的な順位（上位5%など）ではなく絶対的な基準にした理由: 知りたいのは「取りにいく価値があるほど上がった銘柄を拾えたか」。上位5%に入る下限は月によって+25%〜+51%と大きく変わり、相対的な基準では時期によって意味が変わる。超過リターンなので市場全体の上げ下げは差し引かれている
  - +30%にした理由: 毎月46〜173件（母数の3〜11%）あり、どの月も分析に足りる件数がある。+20%は毎月100〜280件と多すぎ、+100%は22か月で229件と少ない
- **着実に上がる型（`--steady`）**: 勝ち銘柄を「起点から120営業日後のTOPIXに対する超過リターンが+30%以上、かつその120日間の最大の下落幅（直前の高値からの下げ）が20%以内」で判定する（+50%以上は大化け）。同じ上昇をまとめる間隔も120営業日。`--export`の書き出し先は`analysis/winner_episodes_steady.csv`（git管理外）。60日で+30%の定義が短期に急騰するテーマ株に偏り、福山通運（9075.T）のような長く着実に上がる銘柄を拾えないため追加した
- **業種平均に対する条件（`--vs-sector`）**: 勝ち銘柄の条件に「同じ業種の他の銘柄（自分を除く）の騰落率の中央値に対しても+30%以上」を加える。業種は`universe.csv`の33業種区分で、流動性フィルタ通過銘柄が10銘柄未満の業種（倉庫・運輸関連業、海運業、水産・農林業、鉱業、石油・石炭製品、空運業の計32銘柄）は判定しない。書き出し先は名前の末尾に`_sector`を付ける（例: `winner_episodes_steady_sector.csv`）。業種全体の上昇（テーマや地合い）に乗っただけの銘柄を外すため。ただし強い業種の主力株も外れるため、目標のリターンではなく、上昇の理由を切り分ける診断用
- **エピソード**: 同じ銘柄が続く起点（前の起点から60営業日以内）で勝ち銘柄になった場合は、一連の上昇として1件にまとめる
  - 安値日: 最初の起点の20営業日前から高値日までで終値が最も安い日（上昇の始まりとみなす）／高値日: エピソードの期間内で終値が最も高い日
- **捕捉の判定**: 安値日の20営業日前から40営業日後までに、PO新規+RSプラス（本番と同じ`filters.py`の`fresh_perfect_order_wide()`とRSプラス）のシグナルが出ていれば「捕捉」。参考としてRS上位10%に入ったかも見る
- **偶然の捕捉率**: 各起点で勝ち銘柄にならなかった銘柄を起点1つだけのエピソードとみなし、同じ手順（安値日・高値日・判定の幅）で捕捉を判定する。勝ち銘柄の捕捉率と比べ、偶然でも届く水準を差し引いて見るため
- **見逃しの型**（捕捉できなかったエピソードを安値日の状態で、上から順に最初に当てはまったものに分類）: データ不足（データが63営業日以下）／POが続いていた（安値日までの20営業日にPOが成立していた＝押し目からの再加速）／200EMAより下から反発／急騰型（安値日から高値日までに1日+10%以上の日がある）／その他
- **見逃しの理由**（見逃しの型とは別に、シグナルが出なかった直接の理由を上から順に分類）: PO新規は出たがRSがマイナス（判定の幅の中でPO新規が出た）／判定の幅より後にシグナル（判定の幅のあと高値日までにシグナルが出た）／PO成立中で新規にならず（判定の幅の中でPOは成立していたが新規にならなかった）／POにならなかった
- **注意**: 勝ち銘柄は結果を見てから選ぶため、この集計はシグナルではなく診断。見つかった条件は`signal_study.py`（シグナルから見る向き）で改めて確かめる。流動性フィルタは現時点の通過銘柄を過去にも当てはめている（上昇する前は流動性が低かった銘柄も含む）。安値日の決め方・捕捉とみなす期間は最初の試行としての仮の値
