# 保有ルールを入れた売買の検証の記録

`analysis/trade_study.py`の実行結果と考察の記録。データが増えたら再実行し、日付の見出しを付けて追記する。

## 目的と方法

- **目的**: `signal_study.py`は60営業日後の結果だけを見るため、長く持ち続けて伸びる銘柄（福山通運など、`winner_study.md`の「着実に上がる型」）の良さが見えない。PO新規+RSプラスで買い、手じまいのルールを変えたときの成績を比べる
- **実行**: プロジェクトフォルダで`uv run python analysis/trade_study.py`。`--export`で取引1件ごとの一覧を`analysis/trades.csv`（git管理外、BOM付きUTF-8）に書き出す。データは読むだけで書き換えない
- **データ**: `ohlcv_history.csv`と`daily_ohlcv.csv`をつなげた約2年分。対象は流動性フィルタ通過銘柄
- **買い**: シグナル（2025-01〜2026-04）の翌日の終値。**売り**: 条件を満たした翌日の終値（同じ終値で売買すると実際より有利になるため）
- **手じまいのルール**
  - ①60日で売る（基準、`signal_study.py`と同じ物差し）／②POが崩れたら売る／③75EMAを終値で割ったら売る／④20日目に200EMAより下なら売り、それ以外は200EMAを割るまで持つ／⑤買ってからの最高値から20%下げたら売る
  - 買い直しあり（シグナルから250営業日見張り、条件が崩れたら売り、戻ったら買い直す）: ②′POが成立している間は持つ／③′75EMAより上の間は持つ
- **成績**: TOPIX（1306.T）に対する超過リターン。買い直しありは、持っていた日だけの騰落率から同じ日だけTOPIXを持った場合の騰落率を引く。PF（プロフィットファクター）＝利益の合計÷損失の合計。1往復0.2%のコスト（手数料・スリッページの目安）込みの成績も出す
- **比べる相手**: シグナル1件ごとに、同じ日にPOが成立している別の銘柄（新規でないもの）を無作為に5件選び（乱数は固定）、同じルールで売買する。日付をそろえて相場の影響を差し引き、「PO新規+RSプラスで買うこと」に、上昇トレンドにある銘柄を買う以上の意味があるかを見る
- **注意**: データの終わりまで売っていない取引は最後の日の終値で評価する（未決済）。取引の期間は重なり同じ相場の影響を受けるため、件数ほどの確からしさはない。200EMAが安定するのはデータ開始から200営業日以降（2025-08ごろ）のため、④は「200EMAが安定してからの買い」に限った表で判断する。流動性フィルタは現時点の通過銘柄を過去にも当てはめている

### 判断基準での判定

あらかじめ決めた基準（①〜⑤: 平均と中央値がどちらも①を上回る・2025年と2026年のどちらでも・比べる相手を上回る／②′③′: 平均とPFが買い直しなしの同じルールを上回る・コスト込みでも・2025年と2026年のどちらでも）を満たしたルールはなかった。②′は全体では平均・PFともコスト込みでも②を上回ったが、2026年はPF（1.3と1.4）とコスト込み平均（+1.4%と+1.6%）でわずかに下回った。

**判断基準の設計に2つの誤りがあった**:
- ①〜⑤で「中央値が①を上回る」を条件にした。早めに損切りして利益を伸ばすルールは小さな負けを増やして大きな勝ちを残す仕組みのため、中央値と勝率は必ず下がり、この条件はもともと満たせない
- ②′③′で「1件あたりの平均」を比べた。持つ期間の違うルールでは、長く持つほど1件あたりの平均は大きくなる。使えるお金に限りがある実際の売買では、持っていた日1日あたりの効率が大事になる

### 読み取れたこと

- **買いの条件（PO新規+RSプラス）に上乗せの効果はなかった**（買い直しなしの①〜⑤）。POが成立している銘柄を無作為に買った場合と差がないか、むしろ負けている。`signal_study.md`・`winner_study.md`と同じ結論
- **成績を変えたのは売りのルール**。③は①に比べて平均を+1.3%から+4.4%に、PFを1.2から2.0に上げ、シグナル・比べる相手の両方、2025年・2026年のどちらでも同じ傾向。ただし利益の86%を上位10%の取引が占め、少数の大きな上昇に頼っている
- **買い直しを入れると、初めてシグナルが比べる相手を上回った**（②′+9.3%と+7.2%、③′+10.2%と+6.3%、2025年・2026年のどちらでも）。ただし平均が上がったのは主に持つ期間が長くなったためで、持っていた日1日あたりの超過リターンは②+0.071%・②′+0.072%とほぼ同じ、③+0.094%・③′+0.065%とむしろ悪化。また200EMAが安定してからの買いに限ると逆転し、未決済も多いため、まだ確かではない
- **損切りを早くすると、福山通運のような銘柄を振り落とす**。75EMA割れ・PO崩れでは決算後の短い押しで売ってしまい、買い直しても売買を繰り返して損が重なる（いわゆる往復びんた）。持ち続けられたのは⑤だけだが、⑤は全体の成績が①と変わらず、損失も大きい（最大-84%）。「振り落とされずに持つ」と「損を小さくする」はぶつかり合う関係にある
- **決算後の押しが行き過ぎた反応で戻るのか、本当の悪化の始まりなのかは、値動きだけでは見分けられない**。値動きだけでできる最善の近似は「長期のトレンド（200EMAの向き）が崩れていなければ押しとみなす」こと。ただし上昇の初め（福山通運の2025年8月）は200EMAがまだ上を向いていないため、この条件でも振り落とされる

### 次に検証したいこと

- **⑥200EMAの向きで使い分ける** → 2026-10-31に検証、効果なし（次の節を参照）
- **⑦TOPIX比の線（株価÷TOPIX）で判断する** → 2026-10-31に検証、作り方に問題があり判断できず（次の節を参照）
- 物差しは、持っていた日1日あたりの超過リターンとPFを主にし、1件あたりの平均は参考にとどめる
- **ポートフォリオ全体での検証**: 同時に持てる銘柄の数を決め、使えるお金に限りがある前提で成績を見る。持つ期間の差・買い直し・売買の期間の重なりを自然に扱える
- **決算データの導入**（今後の検討）: 決算日・業績の中身があれば、決算後の押しを見分けられる可能性がある。J-Quants APIなどが候補だが、データの取得から作り直す大きな作業になる

## 2026-10-31 ⑥200EMAの向きで使い分ける・⑦TOPIX比の線で判断する

- **⑥**: 200EMAが上向き（`SLOPE200_DAYS`＝20営業日前より高い）の間は200EMAを割ったら売り、上向きでない間は75EMAを割ったら売る
- **⑦**: TOPIX比の線（株価÷TOPIX）がその75EMAを割ったら売る
- 物差しに「持っていた日1日あたりの超過リターン」（超過リターンの合計÷保有日数の合計）を加えた。判断は、⑥が200EMAを使うため、200EMAが安定してからの買い（805件、2025-08〜2026-04）に限った表で行う。判断基準: 1日あたりとPFがどちらも③を上回る・コスト込みでも・2025年と2026年のどちらでも・比べる相手を上回る

### 読み取れたこと

- **⑥はすべての基準を満たさず、効果なし**。PFは0.9で損のほうが大きい。200EMAが上を向いている間は押しを許すため、崩れていく銘柄を長く持ってしまい、勝率は22%まで下がった。200EMAを割ったら売る点が同じ④もPF0.9で、200EMAを使って持ちこたえるルールは2つともうまくいかなかった。福山通運のように戻る銘柄より、そのまま崩れる銘柄のほうが多い
- **⑦は作り方に問題があり、判断できない**。1日あたりは③を上回ったが、PFは同じで、2025年は③を下回り、比べる相手にも負けた。平均保有日数は10日で、PO新規（底からの転換）の時点ではTOPIX比の線がまだ75EMAより下にあることが多く、買ってすぐ売ってしまう。「市場全体の押しと個別の押しを分ける」という考えは、まだ正しく確かめられていない
- **この期間（2025-08以降）は、どの売りのルールでも、シグナルが比べる相手（すでにPOが続いている銘柄）を下回った**。上昇相場の中では、底から転換したばかりの銘柄より、すでに上昇トレンドにある銘柄を持つほうが良かった。`winner_study.md`の「PO新規は底からの転換を拾う」という性質と合う
- **「1日あたり」の物差しにも弱点がある**。⑦のように、すぐ売るルールほど値が大きく出やすい。持つ期間の違うルールを公平に比べるには、ポートフォリオ全体での検証が必要

### ここまでのまとめ（いったん区切る）

- 買いの条件（PO新規+RSプラス）に、上昇トレンドにある銘柄を買う以上の効果は見つからなかった。成績を変えたのは売りのルールで、最も安定していたのは③75EMAを割ったら売る（PFが①の1.2から2.0、シグナル・比べる相手の両方、2025年・2026年のどちらでも）
- 福山通運のような着実に上がる銘柄を持ち続ける方法は見つからなかった。値動きだけでは、決算後の押しが戻るのか崩れるのかを見分けられない
- データは約2年分（売りのルールの判断には約1年分）で、ほぼ上昇相場だけ。データが増え、調整局面を含むようになってから再検証する
- 残した課題: ポートフォリオ全体での検証（同時に持てる銘柄の数を決めて比べる）、⑦の作り直し（買った時点でTOPIX比の線が75EMAより上にある場合に限るなど）、決算データの導入
