# エントリーシグナルの検証記録

`analysis/signal_study.py`の実行結果と考察の記録。データが増えたら再実行し、日付の見出しを付けて追記する。

## 目的と方法

- **目的**: 「RSが強い状態に入る初動」を捉えるシグナルを探す。既存のゴールデンクロス（5EMA > 25EMA）を基準に、パーフェクトオーダー（5EMA > 25EMA > 75EMA）への転換などと比べる
- **実行**: プロジェクトフォルダで`uv run python analysis/signal_study.py`（データは読むだけで書き換えない）
- **対象**: 流動性フィルタ通過銘柄（`screening_result.csv`）。銘柄ごとにデータ開始から63営業日はEMAの助走期間として判定に使わない
- **比べるシグナル**:
  - ゴールデンクロス(5/25): 5EMAが25EMAを下から上に抜けた日
  - PO新規: パーフェクトオーダーが成立した日のうち、直前20営業日にパーフェクトオーダーでなかったもの
  - PO新規+75EMA上向き: PO新規のうち、75EMAが5営業日前より上
  - PO新規+RSプラス: PO新規のうち、その日のRS（対TOPIX 21営業日）がプラス
  - PO再開（参考）: パーフェクトオーダーが成立した日のうち、直前20営業日にもパーフェクトオーダーだったもの（短い中断からの再成立）
- **成績の測り方**: 20営業日以内にRS上位10%に入ったか／20日後・60日後のTOPIX（1306.T）に対する超過リターン（平均・中央値・勝率）。「（基準）全銘柄・全日」と比べてシグナルの効果を判断する
- **既知のゆがみ**: 流動性フィルタは現時点の通過銘柄を過去にも当てはめている。上場廃止で一覧から消えた銘柄はデータにないため、結果はやや良く出る可能性がある

### 読み取れたこと

- **ゴールデンクロスはほぼ基準どおり**で、この期間では初動を捉える効果がほとんど見えない。1日42件と多すぎ、2月はRS上位入りの割合が基準を下回った
- **PO新規は初動の検出として安定して有効**: RS上位入りの割合は10か月すべてで基準を上回った。RSプラスを加えるとさらに全月で上回る。件数も1日約8〜10件と目で確認できる量
- **ただし60日後の成績は相場環境しだい**: 中央値が基準を上回ったのは7か月中5か月。3月のシグナルは大きく負け、出遅れ銘柄がまとめて上がった6月は基準を下回った。実際に使うなら手じまい・損切りのルールと組み合わせる前提
- **75EMA上向きの条件は効果がない**（件数・結果ともPO新規とほぼ同じ。25EMAが75EMAを上抜ける時点で75EMAはたいてい上を向き始めているため）
- **PO再開は初動として使えない**（60日後の中央値が基準より悪い）。押し目からの再加速は別の性質のシグナル
- RSプラスを加えたときのRS上位入りの割合の高さは、もともと上位に近い銘柄を選んでいるためある程度当然。60日後のリターンの改善の方を重く見る
- 基準の中央値がほとんどの月でマイナス＝普通の銘柄がTOPIXに負け続けており、大型株が相場を主導していた期間だった
- RSは初動のトリガーというより、トレンド転換の結果として強くなるもの。条件としては補助的に使う

### 事例: タカラトミー（7867.T）

2〜4月のもみ合いでゴールデンクロスが4回出たが、25EMAが75EMAの下にありパーフェクトオーダーは成立せず。5/1の安値2,532円から上昇し、5/13にゴールデンクロス、5/22にパーフェクトオーダーが成立（終値2,983円、RS +5.0%）。その後10/16に4,513円まで上昇。9/9にもみ合いで一度崩れ、9/14に再成立（PO再開）して再加速した。2025年11月には1週間で崩れたパーフェクトオーダー（11/5〜11/12）もあった

### 次に検証したいこと

- 手じまいのルール（例: パーフェクトオーダーが崩れたら手じまう）を入れたときの成績
- 「PO新規+RSプラス」をダッシュボードに出す（ゴールデンクロスのタブの置き換えまたは追加）
- RSの順位や出来高の増加との組み合わせ
- データが増えたら再実行して、結果が安定しているかを確認
